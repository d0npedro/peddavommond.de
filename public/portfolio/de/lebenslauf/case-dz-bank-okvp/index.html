DZ BANK OKVP

Migration der Fiducia-&-GAD-Vertriebsplattformen auf OKVP: entkoppelte Features, OpenShift-Pipelines, Observability. Kein AI-Bestandteil.

  • Java
  • Spring
  • Angular
  • Kafka
  • OpenShift 4
  • Consul
  • Prometheus
  • Grafana
  • Dynatrace
Entkoppelte Features, kontrollierte Delivery, produktionsnahe Observability. Beobachtet in der Delivery. Keine veröffentlichten Performance-Metriken.

Ausgangslage

DZ BANK / adesso, 2020. Vertriebsplattformen von Fiducia & GAD sollten auf die neue SDK-/Microservice-Plattform OKVP.

Schnitt

Entkopplung in unabhängig auslieferbare „Features“; Multi-Stage-Pipelines auf OpenShift; Observability mit Prometheus, Grafana und Dynatrace.

Umsetzung

OKVP zerlegt gewachsene Plattformen in Features. Delivery über OpenShift; Service Discovery über Consul.

Nachweis

Kein AI-/LLM-Bestandteil. Bewertung über unabhängig auslieferbare Features, Pipelines und Observability.

Ergebnis

Entkoppelte Features, kontrollierte Delivery. Keine veröffentlichten Performance-Metriken.
