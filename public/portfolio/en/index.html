04 How I build AI systems

Evaluation, human-in-the-loop, security, observability.

Four principles. Each is observable in public repos or in regulated enterprise delivery. No invented framework names.

Evaluation

Acceptance via tests, CI, checklists, and inspectable state. No model call without a verifiable artifact. Quantitative numbers only once a reproducible harness exists.

Human-in-the-Loop

Agents produce artifacts for human review. No autonomous writes, no automatically trusted decisions.

Security

2FA, RBAC, identity, and GDPR from enterprise delivery. Public demos use synthetic or documented sample data. Responsible deployment before speed.

Observability

Prometheus, Grafana, Dynatrace in banking delivery; stepwise snapshots in the simulator. Behavior has to be visible before it scales.
