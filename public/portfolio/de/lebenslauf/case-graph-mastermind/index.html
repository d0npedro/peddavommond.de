Graph-Mastermind

Ein agentischer Engineering-Workflow analysiert bestehende Repositories, plant Änderungen, arbeitet mit Entwicklungswerkzeugen und Tests und lässt kritische Ergebnisse separat evaluieren.

  • Agent Contracts
  • React
  • TypeScript
  • d3-force
  • CI / Typecheck
Öffentliches Agent-Paket, Live-Demo, Tests, Typecheck, CI und reproduzierbarer Production-Build. Qualitativ beobachtet: nachvollziehbare Artefakte statt Black-Box-Analyse.

Ausgangslage

Independent Applied AI R&D, 2026. In großen, historisch gewachsenen Softwaresystemen fließt erhebliche Entwicklungszeit in Codeverständnis, Fehlerlokalisierung und die Absicherung von Änderungen.

Schnitt

Wiederverwendbares Agent-Paket: ein Coding Agent erhält über AGENT.md, SPEC.md und CHECKLIST.md einen expliziten Arbeits- und Abnahmevertrag. Ein bestimmtes LLM wird bewusst nicht vorausgesetzt.

Umsetzung

Aufgabe / Issue → Planner-Vertrag → Repository-Kontext und Tools → Artefakt (Graph / Architekturansicht) → Tests und Checkliste → menschliche Bewertung. Kein Backend, keine autonomen Schreibzugriffe.

Nachweis

Evaluation läuft. Abnahme heute über CHECKLIST.md, Typecheck, Tests und CI. Quantitative Kennzahlen erst, sobald ein reproduzierbarer Eval-Harness steht.

Ergebnis

Öffentliches Agent-Paket mit Live-Demo. Qualitativ beobachtet: nachvollziehbare Artefakte.
