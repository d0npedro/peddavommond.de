DeutschlandCard — Cloud, Identity, Integration

Paid cloudification of the nationwide loyalty program: Azure AD B2C, Terraform, Kubernetes. Enterprise ground for later AI integration — the case itself is not an AI project.

  • Spring Boot
  • Spring Cloud
  • Azure AD B2C
  • Kubernetes
  • Terraform
  • Oracle OCI
  • Airflow
Services in a scalable Azure environment; existing interfaces remain usable. Observed in delivery, not publicly measured. No volume or latency numbers (NDA).

Starting point

Nationwide loyalty program (direct services Gütersloh, 2023–2026). Partner onboarding, realtime points and campaigns had to move into a controllable cloud.

Cut

Cloudification to Azure; custom Azure AD B2C login journey; infrastructure via Terraform — instead of a big-bang cut.

Implementation

Spring Boot / Cloud services, Azure AD B2C, Terraform, Kubernetes/Azure. Partner APIs stay connectable.

Evidence

No AI/LLM component. Assessed via identity, reproducible infrastructure and still-usable partner APIs.

Result

Scalable Azure environment, observed delivery. No volume/latency numbers (NDA).
